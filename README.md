# Traveler's Rest 

A **medieval tavern-themed management application**. Traveler's Rest brings food and beverage ordering, room rentals, inventory, staff accounts, and sales reporting into one desktop application.

## Documentation


### 🛠️ Configuration & Installation


#### Asset Paths Setup

To ensure the application background and window icons load correctly on your local machine, you need to configure your local file paths inside the source code.
1. Download the Assets: Ensure you have downloaded the OOP_Pictures folder.
2. Update Code Variables: Locate the backg1 and icon variables in your Java code and update their file paths.
Replace the placeholder username (ryce2) with your actual PC account username:
java
// Target variables to update in your local source code:
String backg1 = "C:\\Users\\YOUR_PC_USERNAME\\Downloads\\OOP_PICTURES\\transaction history.png";
String icon   = "C:\\Users\\YOUR_PC_USERNAME\\Downloads\\YOUR_ICON_IMAGE.png";
Use code with caution.
⚠️ Important: In Java strings, remember to use double backslashes (\\) to properly escape your file path separators on Windows systems.
